# GluKaMon — Downloads

This repository exists to **distribute GluKaMon**, a Hammerhead Karoo extension that
displays continuous glucose monitor (CGM) data on your Karoo cycling computer. It holds
no source code — the application source is private. **The releases are the product.**

## Get the app

Everything is attached to the [latest release](../../releases/latest):

| Asset | |
|---|---|
| `GluKaMon.apk` | the app — sideload this |
| `manifest.json` | listing data the Karoo reads to show GluKaMon in its extension library |
| `GluKaMonIcon.png`, `screenshot0–4.png` | artwork for that listing |
| `README.md` | full setup guide — CGM providers, tiles, troubleshooting |
| `RELEASE_NOTES.md` | what changed in this release |
| `LICENSE` | licence terms |

Start with `README.md` for installation and CGM setup. The **Source code (zip / tar.gz)**
archives GitHub attaches to each release are generated automatically and are empty —
there is no source here.

## Important

**GluKaMon is not a medical device.** It is intended only as a convenience for displaying
CGM data while cycling. Never use it for treatment decisions — always confirm readings
with your CGM's own app or a fingerstick.

Your CGM credentials are stored only on your Karoo, encrypted, and are sent only to the
CGM service you choose. Privacy policy: <https://glukamon.com/privacy/>
